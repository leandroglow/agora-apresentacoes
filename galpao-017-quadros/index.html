Como usar

Selecione para editar medidas e identificação. Arraste para mover. Setas movem 1 mm; Shift + setas, 10 mm. Delete remove. Ctrl+Z desfaz. R gira. D duplica.

O encaixe DIN aproxima o centro do componente ao trilho. Trilhos movidos levam os componentes encaixados. A escala na tela é proporcional, não uma régua física.

“Salvar projeto” gera um JSON com os dois quadros. Guarde esse arquivo no Drive: o salvamento automático pertence apenas a este navegador.
